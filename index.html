How ROID-AI Works

From two keyframes to a production-ready in-between in four steps

1

Upload Gengas

Provide two fully composited JPG keyframes at 1920×1080 from your animation timeline.

2

Flow Estimation

The model segments color regions and recurrently refines bidirectional optical flow between frames.

3

ROI Detection

Color filters and motion magnitude maps identify high-priority regions of the frame for synthesis.

4

Download Douga

DCMv2 synthesizes the in-between frame. Download it as a JPG ready for production.

Scope & Limitations

Know what the model supports before you begin

Supported
✓ Fully composited genga (clean line art + color)
✓ JPG file format
✓ 1920×1080 resolution only
✓ Single continuous motion sequences
✓ Generation of one in-between frame
Not Supported
✕ Rough sketches or uncolored line art
✕ Non-JPG file formats (PNG, TIFF, etc.)
✕ Resolutions other than 1920×1080
✕ Scene cuts between unrelated shots
✕ Multi-frame generation in one pass

Frequently Asked Questions

Everything you need to know before using ROID-AI in your production pipeline

ROID-AI currently only accepts JPG files at exactly 1920×1080 pixels. Both Frame 0 and Frame 1 must be fully composited genga — meaning clean, colored anime cels, not rough pencil sketches. Mismatched resolutions or PNG/TIFF formats will cause an error.
Processing time is typically under 15 seconds per pair of keyframes, depending on server load. The DCMv2 model performs bidirectional optical flow estimation followed by ROI-guided synthesis — both stages are GPU-accelerated.
Not yet. The current version of ROID-AI generates exactly one in-between frame per request. Multi-frame batch generation (×2, ×4) is planned for a future release. For now, you can chain multiple requests sequentially.
ROID-AI handles moderate-to-fast motion well due to its ROI detection stage, which emphasizes high-motion regions. However, extremely large displacements may produce artifacts. Scene cuts or unrelated shots should never be used as input pairs.
The output is a 1920×1080 JPG at studio-standard quality, intended as a starting point for your production pipeline. We recommend reviewing the output before final render, particularly for complex multi-character scenes.
No. Uploaded frames are processed in memory and deleted immediately after the result is returned. We do not store, log, or use your artwork to train future models. All processing is end-to-end encrypted.
